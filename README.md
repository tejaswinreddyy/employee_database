# Employee Database System 🧑‍💼

A web application built with React.js to manage and display employee records. This project allows users to view, add, edit, and delete employee information using a clean and responsive UI.

## 🌐 Live Demo

[https://employee-database-bkov.vercel.app/](https://employee-database-bkov.vercel.app/)

## 🚀 Features

- View all employees in a structured table
- Add new employee records
- Edit existing employee details
- Delete employee entries
- Fully responsive design

## 🛠 Built With

- React.js
- React Router DOM
- Axios
- CSS
- Vercel (for deployment)
